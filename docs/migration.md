# 標準 RMK から ZMK への移行

このリポジトリは Cornix 用のコミュニティ版基板定義を使います。
左右とも nRF52840 の Cornix LP を対象とし、別機種の UF2 は使いません。
基板モジュールの資料ではパーティション定義 v2.3 以降は直接 UF2 を書けるとしていますが、
手元の本体・ブートローダーが同じ条件かは、ビルド成功や `Release: 16` だけでは判断できません。

## 1. 書き込み前に保存するもの

- 現在の `.vil` バックアップ。これは **RMK 用キーマップ**であり、ファームウェアそのものではありません。
- 手元の Cornix に適合する **標準 RMK の左右 UF2**。メーカーの配布物から事前に取得します。
- 現在のファームウェア版が分かる画面や情報。
- 左右それぞれの UF2 ドライブの `INFO_UF2.TXT`。

個人のバックアップやペアリング情報は、この公開リポジトリにコミットしません。
古い標準 UF2 や、不明な個体向けの復元ファイルは同梱していません。

## 2. ブートローダー情報を読む（ファームウェアは書き込まない）

1. 片側だけをデータ通信対応 USB ケーブルで Mac に接続します。
2. リセットボタンを素早く2回押し、UF2 ドライブを表示します。
   左側では C と V の間の下、親指キーのすぐ上にある小さなボタンです。
   [位置の写真](https://github.com/numachang/cornix-zmk-custom/blob/ade15a303257ffb2c11357839ff39199b863b087/docs/images/12-reset-button.png)も参照してください。
3. リポジトリのルートで `bash scripts/bootloader-info.sh` を実行します。
4. 左右を取り違えないように、どちら側の出力か記録します。
5. もう片側でも同様に情報を取得します。

スクリプトは `/Volumes/*/INFO_UF2.TXT` を読むだけです。UF2 のコピー、設定消去、
ブートローダーの変更は行いません。ドライブが出ない場合は書き込みを進めず、
ケーブル・操作方法・本体の対応を確認します。

## 3. 同じビルドの左右ファイルを用意する

Actions の成功した **同じ実行**から `firmware` アーティファクトをダウンロードします。
通常用は `cornix-left.uf2` と `cornix-right.uf2` です。
reset と付いたファイルは設定消去用で、通常ファームウェアとは区別します。

リセット用 UF2 は Bluetooth のペアリングや保存済み設定を消去します。
新しいファームウェアをビルドしたという理由だけで、毎回使う必要はありません。
初回移行や左右の再ペアリングで必要な場合に、バックアップ・復元手段を確保したうえで使います。

## 4. 適合確認後の書き込み手順

1. Mac の古い Cornix の Bluetooth 登録を解除します。
2. 必要な場合に限り、左には `cornix-reset-left.uf2`、右には `cornix-reset-right.uf2` を書き込みます。
3. 左の UF2 ドライブに `cornix-left.uf2`、右には `cornix-right.uf2` をコピーします。
4. 左右を再起動し、左右間の接続を待ちます。
5. まず左 USB 接続で通常入力を確認し、その後 `Cornix Kobito` として Bluetooth に登録します。

片側だけを別のビルドへ変更しません。左右の分割通信仕様が異なると接続できなくなります。
元の KobitoKey 用 UF2 は、Cornix 用として使いません。
手元のハードウェア適合が確認できるまでは、この段階を実行しません。

## 5. 入力確認

- QWERTY・記号が macOS の US/ANSI 配列で意図どおり出る。
- Space は左親指の中央、Ctrl はその右隣。
- Space をタップすると空白。押しながら H/J/K/L で左/下/上/右。
- Command を先に押し、Space を180ms以上保持してから **Spaceを先に**離すと、
  元の `retro-tap` により Command+Space が出る。
- 親指 Enter をタップすると改行、長押しして Q で1。長押しだけで離しても改行しない。
- D+F が英数、J+K がかな。Fn・数字・記号のレイヤーでも同じ物理位置で確認する。
- Q+W と A+S は基本レイヤーでのみ Esc/Tab。
- 親指 Bksp+Symbol で BT レイヤー、Ctrl または右 Alt の位置で通常へ戻る。
- 元の40キー以外の10位置は、どのレイヤーでも入力されない。ノブ回転も入力されない。
- 左右間の再接続、スリープ復帰、Bluetooth 切替。

元にない外周キー、BT/MOUSE キー、Studio Unlock は追加しません。
Layer 4 等のトラックボール用定義は保持しますが、Cornix にはその自動発動元がありません。

### ZMK からこの40キー設定へ更新する場合

通常用の左右 UF2 を同じビルドから書き込みます。ペアリングを消す reset UF2 は不要です。
以前 Studio の Save でキーマップを変更した場合、その保存済み配置が新しいソースより
優先されます。Studio で Unlock できる場合は **Restore Stock Settings** を使います。
実機に解除用キーがない場合は設定リセット用 UF2 を書いてから通常用 UF2 を書きます。
設定リセットは Bluetooth のペアリングも消すため、左右と Mac を再ペアリングします。
新しい構成には追加の Unlock キーがありません。Studio で変更を保存していなければ
設定リセットは不要です。

これらは実機で確認する項目です。ソース比較テストとビルドだけでは検証できません。

## 標準 RMK へ戻す

1. 保存しておいた、手元の Cornix に適合する標準 RMK の左右 UF2 をそれぞれ書き込みます。
2. 左右の接続と Mac 側の Bluetooth を設定し直します。
3. Vial/vitaly から保存しておいた `.vil` を適用します。

ZMK のリセット UF2 を書くだけでは、標準 RMK には戻りません。
UF2 の通常書き込みができない場合のブートローダー復旧は別の作業です。
